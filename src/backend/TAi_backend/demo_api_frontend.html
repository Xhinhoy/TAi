GET /api/v1/users/{uid}/profile - Obtener perfil
▼
Propósito: Obtener el perfil completo del usuario (intereses, preferencias, ubicación)

Obteniendo perfil...

Código de ejemplo (React/JS):

const getProfile = async (uid, token) => { const response = await fetch( `http://localhost:8000/api/v1/users/${uid}/profile`, { headers: { 'Authorization': `Bearer ${token}` } } ); const profile = await response.json(); return profile; }
POST /api/v1/chat/message - Chat con agente IA
▼
Propósito: Conversación natural con el agente de viajes. El agente tiene acceso a herramientas (Google Places, TripAdvisor) y recuerda el contexto de la conversación.
Mantén el mismo session_id para conversaciones continuas

El agente está pensando y consultando APIs...

Código de ejemplo (React/JS):

const sendChatMessage = async (message, userId, sessionId, token) => { const response = await fetch( 'http://localhost:8000/api/v1/chat/message', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` }, body: JSON.stringify({ user_id: userId, session_id: sessionId, message: message }) } ); const data = await response.json(); return data; // { response: "...", actions: [], places: [] } }
POST /api/v1/itineraries/generate - Generar itinerario con IA
▼
Propósito: Genera un itinerario completo usando el agente IA con herramientas. El agente consulta Google Places y TripAdvisor para crear un plan realista basado en el perfil del usuario.
⚠️ Nota: Este endpoint puede tardar 30-60 segundos porque el agente razona, usa herramientas y genera un plan detallado.

Generando itinerario con IA... Esto puede tardar hasta 60 segundos

El agente está:

  • Razonando sobre tus intereses
  • Buscando lugares en Google Places
  • Consultando reviews en TripAdvisor
  • Optimizando la ruta
  • Generando el plan final

Código de ejemplo (React/JS):

const generateItinerary = async (city, days, title, token) => { const response = await fetch( 'http://localhost:8000/api/v1/itineraries/generate', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` }, body: JSON.stringify({ city: city, days: days, title: title || null }) } ); const itinerary = await response.json(); return itinerary; // { id: "...", title: "...", city: "...", days: 3, items: [...] } }

▼
Propósito: Actualizar los intereses del usuario para personalizar recomendaciones

Actualizando intereses...
